# v4.6.0 First Hyperliquid Testnet Canary Runbook

## Safety
This first canary is read-only. Do not provide a private key to this script.

## 1. Prepare
From the repository root:

    python -m venv .venv
    .venv\\Scripts\\activate

On Linux/macOS:

    source .venv/bin/activate

Install:

    pip install -r requirements-testnet.txt

## 2. Run
Default ETH 1m / 10 minutes:

    python scripts/run_testnet_canary.py

Or:

    python scripts/run_testnet_canary.py --coin ETH --duration-seconds 600

## 3. Expected Output
You should see completed 1m candle messages such as:

    CANDLE #1 ETH 1m ts=... close=...
    CANDLE #2 ETH 1m ts=... close=...

and finally:

    CANARY_OK received_candles=N

## 4. Stop Conditions
Stop the canary if:
- the process repeatedly disconnects;
- timestamps move backward;
- malformed messages are observed;
- the endpoint is not the Testnet endpoint;
- any code path unexpectedly requests signing or private-key material.

## 5. Pass Criteria
For a 10-minute canary:
- connection succeeds;
- 1m candles are received;
- no out-of-order candle is accepted;
- duplicate candles do not create duplicate callback events;
- process exits cleanly;
- no private key is loaded.

## 6. Important
This is a market-data canary, not a trading run.

Do not enable order submission yet.

## 7. Next Stage
After this canary passes, connect the stream to:
Runtime Event Bus
→ Durable Event Store
→ 1m canonical state
→ ChanLun engine
and run a read-only 30-minute Agent soak.

Only after the read-only Agent soak is stable should we perform a separately gated Testnet execution canary.
