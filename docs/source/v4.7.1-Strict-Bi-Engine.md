# v4.7.1 Strict Bi Engine

## Purpose

Implement the 1M same-level ChanLun Bi layer as a deterministic state machine over confirmed fractals.

## Frozen rules

1. Only confirmed TOP/BOTTOM fractals are accepted.
2. A Bi requires adjacent effective opposite fractals.
3. TOP -> BOTTOM is a DOWN Bi; BOTTOM -> TOP is an UP Bi.
4. The two fractal center indices must differ by at least 2, leaving at least one complete processed candle between them.
5. Same-type fractals do not form a Bi.
6. A more extreme same-type fractal supersedes the previous endpoint.
7. If a previously emitted Bi endpoint is superseded, emit BI_ENDPOINT_REVISED and mutate that Bi endpoint deterministically.
8. Price order must be valid: UP requires top > bottom; DOWN requires bottom < top.
9. Non-confirmed fractals are ignored.
10. Fractal input must be chronological; replaying the same fractal id is idempotent.

## Events

- BI_ANCHOR_SET
- FRACTAL_SUPERSEDED
- FRACTAL_IGNORED_SAME_TYPE
- FRACTAL_REJECTED_NO_INTERMEDIATE_CANDLE
- FRACTAL_REJECTED_PRICE_ORDER
- BI_CONFIRMED
- BI_ENDPOINT_REVISED

## State

BiEngine.state exposes (direction_bit, phase_bit):

- (0,0) = DOWN / BUILDING
- (0,1) = DOWN / EXTENDING
- (1,0) = UP / BUILDING
- (1,1) = UP / EXTENDING

This compatibility representation is intentionally small; the authoritative state remains the typed Bi object and event stream.

## Source basis

The implementation follows the original definitions in 教你炒股票 第62、65课: a Bi is formed between adjacent effective top and bottom, and in practical analysis the top and bottom should have at least one K-line between them. The implementation applies that rule to the already inclusion-processed 1M sequence.
