# v4.4.11 — Hyperliquid API & WebSocket Verification / Conformance Test Specification

## 1. Purpose

This document converts the v4.4.10 Hyperliquid adapter open verification items into an executable verification and certification plan.

It separates:

- official-documentation facts;
- adapter assumptions;
- executable tests;
- observed evidence;
- production certification decisions.

Current official Hyperliquid documentation confirms that the public API exposes REST and WebSocket interfaces, with mainnet REST at `https://api.hyperliquid.xyz` and mainnet WebSocket at `wss://api.hyperliquid.xyz/ws`. The documentation also states that automated clients must handle server-side disconnects and reconnect, and that missed data can be recovered through snapshot acknowledgement and/or Info requests. citeturn1search3turn1search11

## 2. Verification Principle

No venue behavior becomes a production invariant merely because it appears plausible.

Each behavior must reach one of:

VERIFIED
PARTIALLY_VERIFIED
DOCUMENTED_ONLY
TEST_FAILED
NOT_APPLICABLE
UNKNOWN

Only VERIFIED behavior may be used as a hard production invariant.

DOCUMENTED_ONLY means the behavior is documented but has not yet passed the project's controlled test.

## 3. Evidence Hierarchy

Priority:

1. current official Hyperliquid documentation;
2. controlled test execution against the intended environment;
3. captured raw API/WebSocket evidence;
4. adapter normalization evidence;
5. replay result;
6. secondary SDK behavior;
7. general model assumptions.

Lower-level evidence cannot silently override higher-level authoritative evidence.

## 37. Certification Failure Rules

Certification FAIL if:

- unknown order can be blindly retried;
- duplicate fill can double-count;
- reduce-only can silently disappear;
- position drift is ignored;
- reconnect resumes trading without required reconciliation;
- stale metadata can create unsafe orders;
- lease/fencing is bypassed;
- authentication failure leaves execution enabled;
- rate-limit retry causes uncontrolled amplification.
