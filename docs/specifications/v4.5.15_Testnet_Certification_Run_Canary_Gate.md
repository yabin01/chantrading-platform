# v4.5.15 — Testnet Certification Run & Canary Gate

## Objective
v4.5.15 defines the first executable certification gate before an extended Hyperliquid Testnet run.

## Precheck Gate
A run cannot start unless all prechecks pass:
- configuration loaded;
- explicit Testnet mode;
- trading guard enabled;
- durable Event Store ready;
- replay path ready.

## Certification Lifecycle
PRECHECK → RUNNING → PASSED / FAILED

A clean certification requires:
- replay_equivalent = true;
- drift_events = 0.

## Canary Sequence
1. 5–10 minute connectivity/data canary;
2. 30 minute controlled run;
3. 2 hour run;
4. 24 hour soak;
5. 72 hour soak;
6. 7 day soak.

Advancement is evidence-based.

## First Canary Scope
Verify:
- Testnet endpoint;
- authentication/signing boundary;
- 1-minute market-data ingestion;
- event persistence;
- order lifecycle;
- fill ingestion;
- position reconciliation;
- watchdog;
- recovery;
- replay equivalence.

The first canary is infrastructure certification, not strategy-performance evaluation.

## Trading Guard
The certification runner must not enable trading by itself. Trading permission must come from the existing risk/execution guard.

## Failure Rules
Certification fails on unresolved reconciliation drift, replay mismatch, failed recovery, terminal watchdog halt, unresolved UNKNOWN order, or unreconciled final venue position.

## Evidence Package
Archive:
- runtime report;
- durable event store;
- reconciliation report;
- final venue snapshot;
- replay result;
- runtime/watchdog events;
- configuration fingerprint.

## Production Boundary
v4.5.15 is Testnet-only. Passing certification does not prove profitability, strategy robustness, or Mainnet readiness.
