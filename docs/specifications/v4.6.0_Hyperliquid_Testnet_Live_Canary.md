# v4.6.0 — Hyperliquid Testnet Live Canary

## Objective
v4.6.0 is the first live Testnet runtime boundary. It connects to the real Hyperliquid Testnet WebSocket and consumes live 1-minute candles.

Official Testnet endpoints:
- REST: https://api.hyperliquid-testnet.xyz
- WebSocket: wss://api.hyperliquid-testnet.xyz/ws

## Scope
The first canary is intentionally read-only.

It verifies:
- real Testnet connectivity;
- 1m candle subscription;
- message decoding;
- duplicate suppression;
- timestamp ordering;
- runtime callback delivery;
- clean shutdown.

No order submission or wallet signing is performed by this module.

## Canary
Default target:
- symbol: ETH;
- interval: 1m;
- duration: 10 minutes.

A successful run must receive live 1m candles without out-of-order events and must shut down cleanly.

## Safety
This stage does not require a private key and cannot submit an order.

Execution is a separate gate and will only be enabled after the live market-data canary passes.

## Next Step
v4.6.1 should connect live candles to the existing canonical Event Schema, Durable Event Store and ChanLun 1m state pipeline, then run the first full read-only Agent soak.

## Production Boundary
Testnet-only. Read-only. No Mainnet authorization.
