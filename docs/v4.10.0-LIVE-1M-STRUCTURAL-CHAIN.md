# v4.10.0 — Live 1M Structural Chain

## 1. Scope

v4.10.0 extends the read-only Hyperliquid Testnet 1M market-data path from:

Candle → Fractal → Bi

to:

Candle → Fractal → Bi → Strict Segment → Strict Center

The operating timeframe remains locked to 1M.

## 2. Runtime contract

Live1MStructureEngine accepts only LiveCandle events whose interval is `1m`.

For each accepted candle:

1. FractalEngine processes the candle.
2. Only confirmed fractals are passed to BiEngine.
3. Only resulting Bis are passed to SegmentEngine.
4. Only `SEGMENT_CONFIRMED` events are passed to CenterEngine.
5. Center events are emitted as read-only LiveStructureEvent records.

No order submission, position management, BUY/SELL signal, MACD divergence, Ai upgrade, or timeframe switch is performed by this layer.

## 3. Structural state

The runtime exposes:

- `latest_candle`
- `latest_fractal`
- `latest_bi`
- `latest_segment`
- `latest_center`

The snapshot exposes the corresponding IDs for deterministic observability.

## 4. Determinism boundary

The live integration does not reinterpret or mutate the underlying ChanLun engines. It only forwards confirmed objects between already-frozen layers.

Segment confirmation is the boundary for CenterEngine input. This prevents incomplete Segment candidates from becoming Centers.

## 5. Testnet safety

The transport remains read-only. Hyperliquid Testnet WebSocket market data can drive the structural engine, but this version does not authorize trading or send exchange orders.

## 6. Next gate

The next certification target is an end-to-end canary that proves:

- live 1M candles are received;
- duplicate candle timestamps are ignored;
- chronological ordering is preserved;
- confirmed structural events are produced without exceptions;
- the runtime can reconnect and resume;
- replay of the captured event stream is deterministic.

Only after these conditions are demonstrated should the long-duration Testnet soak run be started.
