# v4.11.0 — Live 1M Deterministic Soak & Replay

## Objective
Make the Live 1M structural pipeline reproducible from an ordered candle recording.

Canonical replay boundary:

Hyperliquid Testnet 1M candle -> recorded candle -> Live1MStructureEngine -> structural events -> snapshot/hash.

## Determinism contract
For an identical ordered candle sequence:
- emitted event sequence is identical;
- event payloads are canonically serializable;
- final structural snapshot is identical;
- canonical event hash is identical;
- replay does not submit orders or mutate the recording.

The recorder rejects duplicate and out-of-order candle timestamps.

## Hash boundary
The v4.11.0 hash covers the canonical structural event sequence using SHA-256 over canonical JSON.
This is an integrity/determinism fingerprint, not a signature or proof of market-data authenticity.

## Soak gate
A future soak runner will record accepted candles, structural events, reconnect lifecycle, rejected duplicates/out-of-order data, final snapshot, and replay hash.

Certification requires offline replay of the recorded candle sequence and equality of the live-run structural event hash and snapshot.

## Safety boundary
This release remains read-only. No wallet, order submission, position management, or execution path is enabled.
